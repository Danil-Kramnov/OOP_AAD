## Glossary
| Term | Meaning |
| --- | --- |
| Borrower | Person or organisation that reserves equipment. |
| Reservation | Equipment held for a borrower for set dates; provisional or confirmed. |
| Equipment model | A type of equipment, e.g. adult buoyancy aid. |
| Equipment item | One physical, tracked piece of equipment. |
| Kit | Items used together; usable only when complete. |
| Batch | Items delivered together by one supplier. |
| Ready | Present, complete, dry, inspected and not restricted. |
| Restriction | A limit on using an item, a model or a batch. |
| Eligibility evidence | Proof of training, supervision or an approved instructor. |
